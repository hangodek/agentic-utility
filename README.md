# Agentic Utility

A collection of AI agent rules, guidelines, and utilities for pair-programming and learning workflows.

---

## Quick Start: Import Learning Rules into Any Project

Whenever you clone a starter repo or start a new project, run this one-liner inside the project root:

```bash
curl -fsSL https://raw.githubusercontent.com/hangodek/agentic-utility/main/learning/AGENTS.md -o AGENTS.md
```

### What this includes:
- **Learning-Oriented Agent Guidelines:** Mentorship principles, mental model breakdowns, data flow traces, and anti-pattern warnings.
- **Git Policy:** Conventional Commits standard with zero autonomous pushes.
- **Architecture Conventions:** Separation of Concerns (*"Skinny Everything"*), explicit call paths, and layer definitions.
- **Pedagogical Standards:** In-code intent annotations, structured mental models, and beginner-accessible explanations.
- **TDD Workflow:** Red-Green-Refactor as an educational tool.
